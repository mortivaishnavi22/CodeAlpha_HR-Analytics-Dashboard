📊 **HR Analytics Dashboard using Power BI** 

**OBJECTIVE-**


The objective of this project is to analyze employee data and identify patterns related to employee attrition. This dashboard provides insights that help HR teams understand workforce trends and support data-driven decision-making.



**PROJECT OVERVIEW-**

Throughout this project, I:

1.Explored HR datasets to extract insights

2.Built an interactive dashboard using Power BI

3.Visualized key HR metrics

4.Analyzed employee distribution and attrition trends.


**TOOLS AND TECHNOLOGIES-**

-Microsoft Power BI

-Microsoft Excel

-Power Query

-DAX (Data Analysis Expressions)


**STEPS FOLLOWED-**

1️⃣ **Data Gathering**

-Imported raw .csv dataset into Power BI

-Loaded the dataset into Power Query Editor

2️⃣** Data Cleaning**

-Removed empty columns and duplicate values

-Handled missing data and errors

-Renamed columns for better readability

-Ensured correct data types using auto-detect

3️⃣ **Data Processing**

-Structured and organized data for analysis

-Created relationships between fields 

-Prepared data for visualization in Power BI

-Used existing dataset fields to analyze attrition and employee trends

4️⃣ **Data Analysis**

Created various visualizations such as:

-Bar charts

-Pie and Donut charts

-KPI cards

-Tables and Matrix

-Used filters and slicers for better interactivity

-Designed dashboard layout for easy understanding





**KEY LEARNINGS-**

1.Power BI dashboard development

2.Data cleaning using Power Query

3.Creating interactive visuals
